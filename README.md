# Synapse Immersion

Build a premium, modern, highly interactive one-page microsite for:

ONE DAY AT SYNAPSE (ODAS)

IMPORTANT CREATIVE DIRECTION:

DO NOT replicate the visual style of the uploaded ODAS PDF.

The PDF is ONLY the source of truth for:

- event name

- session names

- event experience

- messaging

- content/information

Do NOT copy:

- the PDF's illustrations

- orange/red blocks

- ticket shapes

- hand-drawn lines

- barcode elements

- collage style

- presentation-slide layouts

- fonts

- illustrations

- visual compositions

The website should feel completely different from the PDF.

Think of this as a premium digital experience created by a cutting-edge creative agency.

Reference the sophistication of:

- modern creative agency websites

- Apple product launches

- Awwwards-winning agency websites

- Stripe

- Linear

- modern editorial websites

- immersive brand experiences

But DO NOT directly copy any of these websites.

==================================================

BRAND

==================================================

The website is for Synapse Advertising.

Use the existing Synapse brand identity from:

https://synapseadvertising.in/

The website should feel unmistakably like Synapse.

Use the Synapse logo and visual identity where appropriate.

IMPORTANT:

Do not use the colour palette of the ODAS PDF.

Instead, derive the colour system from the actual Synapse brand.

Primary palette:

- warm/off white

- deep charcoal

- black

- Synapse orange

- subtle gold/yellow accent

Keep the overall palette sophisticated and restrained.

Suggested direction:

70% neutral / white space

20% charcoal / black

10% orange + gold accents

Orange should be an accent, NOT the dominant background colour.

Avoid excessive gradients.

==================================================

The website should feel like:

"AN INTERACTIVE DOOR INTO SYNAPSE."

The visitor is not simply reading about an event.

The entire website should have a strong sense of movement and discovery.

==================================================

HERO — THE MAIN EXPERIENCE

==================================================

Use the uploaded photograph of the actual Synapse office entrance.

Do NOT put a large amount of text over the photograph.

Initially make the photograph feel cinematic and almost full-screen.

Minimal text:

ONE DAY AT SYNAPSE

Then:

STEP INSIDE.

Small supporting text:

An immersive experience inside the world of Synapse.

CTA:

APPLY NOW →

The hero should feel spacious and premium.

==================================================

DOOR OPENING INTERACTION

==================================================

This is the signature interaction of the website.

Use the uploaded office entrance photograph.

As the user scrolls:

1. Slowly zoom into the entrance.

2. Focus attention toward the doors.

3. Create the illusion that the actual glass doors are opening.

4. Split/mask the image into the two door panels.

5. Animate the panels apart.

6. Reveal the next section behind the doors.

7. Transition seamlessly from photography into the digital experience.

The animation should feel realistic and cinematic.

NO cartoon door animation.

NO cheesy transitions.

Think:

"the website is physically opening the Synapse office to you."

Once the doors open, reveal:

WELCOME INSIDE.

Then:

ONE DAY AT SYNAPSE

ODAS

Large typography.

Headline:

WHAT HAPPENS

INSIDE SYNAPSE?

One Day at Synapse is an immersive experience designed to take visitors inside the thinking, strategy and execution behind marketing campaigns.

Use the actual information from the uploaded PDF.

Do not invent claims.

Create four large typographic interactive statements:

EXPLORE AI

MEET SPECIALISTS

ACROSS FUNCTIONS

UNDERSTAND

CAMPAIGNS

EXPERIENCE

EXECUTION

Each item should animate subtly as the user scrolls.

Do not use cards everywhere.

Use typography, whitespace and motion instead.

ANIMATION

==================================================

Use GSAP / Framer Motion.

Use scroll-driven animation throughout the experience.

Animations should include:

- cinematic image zoom

- door opening

- text reveal

- kinetic typography

- horizontal scrolling

- parallax

- line drawing

- scale transitions

- masked image transitions

- subtle hover interactions

Motion should have purpose.

Do not animate everything just for the sake of animation.

The website should feel smooth and expensive.

==================================================

MOBILE

==================================================

The mobile version should NOT simply be a compressed desktop site.

Design a dedicated mobile experience.

The door interaction should still work.

Use:

- vertical storytelling

- large typography

- swipe/scroll interactions

- sticky CTA

- simplified navigation

Keep APPLY NOW easily accessible.

==================================================

FINAL EXPERIENCE

==================================================

The user journey should feel like a short film:

1. They see the real Synapse entrance.

2. They scroll.

3. The door opens.

4. They enter Synapse.

5. They discover ODAS.

6. They move through the journey from brief → insight → strategy → storytelling → execution → big idea.

7. They reach the final CTA.

The website should make the visitor feel:

"I've actually stepped inside Synapse."
